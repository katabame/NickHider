# NickHider

匿名化プラグイン

## プラグイン概要
自分のプレイヤー名を任意の文字列に変更できるプラグインです  
現状、以下の項目に対応しています
* ネームプレート
* ターゲットバー
* パーティーリスト
* ソーシャルウィンドウ
* キャラクターウィンドウ
